## CodePulse HUD v1.4.0

首个独立维护的 CodePulse HUD 稳定版本，只发布 Windows x64 安装包。

### HUD 体验

- 同一项目中的多个 agent 使用独立卡片并由共享细框归组；状态、计时、上下文、动效与操作互不干扰。
- 打开 Codex CLI 后无需先发消息即可恢复项目；Kimi 额度也会在 HUD 启动时读取。
- 等待阶段使用“已读”，真正结束后使用“完成”，更清楚地区分中间提醒和最终结果。
- 空闲、取消和已确认结果统一遵守用户设置的卡片停留时间。
- 每张卡片右上角增加紧凑的 `×` 临时关闭操作；控制区宽度固定，按钮出现与消失不会挤压其它信息。

### 独立产品与维护

- 使用独立的 CodePulse HUD 产品名、应用 ID、安装包名称、用户数据目录和 GitHub 更新源。
- 发布流程收束为经过验证的 Windows 安装包，不再宣称未经持续验证的 macOS 或 Linux 支持。
- 移除 HUD 不使用且无法正常打开的统计后台、SQLite 历史存储和相关原生依赖。
- README 与设计文档改为 HUD 单一产品说明，并保留对原 CodePulse 项目与 MIT 许可证的简短归属。

### 从旧版迁移

旧版 CodePulse 与 CodePulse HUD 使用兼容的 hook 配置和相同的本机端口，请勿同时运行。建议先退出并卸载旧版，再安装 `CodePulse-HUD_1.4.0_x64-setup.exe`；首次启动会重新检查必要的 hook 配置。Codex 用户仍需在 `/hooks` 中信任 CodePulse hook。
