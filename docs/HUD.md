# CodePulse HUD 设计说明

## 定位与边界

CodePulse HUD 是面向 Windows 的独立 HUD 产品，基于 `noeigenstate/CodePulse` 的实时 hook、状态机和本地服务扩展而来。它只维护紧凑、常驻、低打扰的 HUD 表现，不再同时承担原项目 Dashboard 与历史统计产品的职责。

当前稳定版本为 `v1.4.0`。应用使用独立的 `productName`、`appId`、安装包名称、用户数据目录和更新源；内部保留 `CodePulse` hook 标识及本地协议，以兼容现有 CLI 配置。因此 HUD 与旧版 CodePulse 不应同时运行。

## 视觉语义

HUD 只使用两层主要颜色：

- 中性：空闲、普通执行、已取消，以及已经确认的终结状态；
- 橙色：等待用户、未读完成，或未读故障。

状态文字解释发生了什么，橙色只回答“现在是否值得看”。运行时状态仍保持完整，不会为了视觉简化而合并生命周期。

| HUD 层级 | 运行时状态                                     | 含义               |
| -------- | ---------------------------------------------- | ------------------ |
| `quiet`  | `idle`、`cancelled`、已确认的终结状态          | 无需处理           |
| `active` | `prompt_submitted`、`thinking`、`tool_running` | 正常工作中         |
| `notice` | 未读 `done`                                    | 已完成，值得看一眼 |
| `action` | `waiting_permission`、`waiting_user_input`     | 正在等待用户操作   |
| `fault`  | 未读 `error`、`timeout`、`usage_limited`       | 任务受阻，需要检查 |

## 项目与 agent 卡片

- 工作区是归组边界，每个 agent 始终拥有自己的卡片。
- 同一工作区有多个 agent 时，卡片按 Claude → Codex → Kimi → Grok 纵向紧挨排列，并使用克制的共享外框。
- 状态、计时、上下文、注意动效、确认和临时隐藏全部按卡片独立计算；一个 agent 的操作不会连带同项目中的其它 agent。
- 单 agent 项目不显示共享外框，维持紧凑单卡表现。
- 纯额度信息只进入底部用量条，不产生没有真实工作区的空卡片。

## 确认、隐藏与停留时间

- 等待授权或输入时，按钮显示“已读”。点击只确认用户看到了提醒，不会伪造状态变化；只要 CLI 仍在等待，卡片仍保持橙色。
- 成功结束且未读时，按钮显示“完成”。确认后恢复中性，并开始应用结果停留时间。
- 故障、疑似卡住和用量受限使用“已读”；后续真实事件仍可正常推进状态。
- 卡片右上角 `×` 只临时隐藏当前卡片，不终止任务、不确认结果，也不更改生命周期。
- 纯额度刷新不会解除临时隐藏；新的真实生命周期活动会按原有 reducer 规则让卡片重新出现。
- 空闲、已取消和已确认结果统一遵守用户选择的 10 / 30 / 60 / 120 / 240 分钟停留时间。
- 控制区始终保留固定宽度，因此“已读/完成”按钮出现或消失时，项目名称、状态、计时和用量不会左右跳动。

## 窗口行为

- 透明、无边框、置顶并跳过任务栏；状态触发显示时不主动抢焦点。
- 优先选择主屏右侧最远的副屏；没有合适副屏时回退到其它显示器或主屏。
- 窗口固定在目标工作区右上角，并根据项目卡片和用量条的自然高度伸缩；超出工作区才滚动。
- 原生窗口 opacity 固定为 `1`，设置仅调整 HUD 面板背景 alpha，避免文字随背景一起变淡。
- 默认浅色、92% 背景透明度、单列和常亮提示；可选择深色/自动主题、网格布局以及呼吸/脉冲动效。
- 设置使用独立普通窗口；主 HUD 保持紧凑。

## 实时与本地数据

- 启动时执行一次本机会话恢复，使 Claude、Codex 等 CLI 即使尚未开始新对话也能出现已有项目状态。
- 运行期间主要依赖原生 hook；默认关闭持续递归监听和周期性全盘扫描。
- Kimi 额度在 HUD 启动时读取，尚未打开 Kimi 对话时也可以进入用量条。
- hook API 仅绑定 `127.0.0.1:17888`，并使用本机 token 认证。
- HUD 不建立 SQLite 活动历史，不提供统计后台，也不持久化提示词全文。

## 发布约定

- 新版本只发布 Windows x64 NSIS 安装包，命名为 `CodePulse-HUD_<version>_x64-setup.exe`。
- 稳定版本使用普通语义版本 tag，例如 `v1.4.0`；短期试验不再堆积多个公开 HUD 预发布版本。
- 更新检查与下载只指向 `LBW-C137/CodePulse-HUD`。
- 发布前必须通过 typecheck、测试、smoke、格式检查和本地 Windows 安装包验证。
- `upstream` 仅用于有选择地读取原项目修复，不作为 HUD 的发布远端；是否吸收上游变更由维护者逐项判断。
